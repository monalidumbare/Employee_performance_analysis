
# 📊 Employee Performance & HR Analytics

## 📌 Project Overview

Employee Performance & HR Analytics is a Data Analytics project designed to analyze employee information, salary distribution, department productivity, work mode, education level, employee performance, and attrition.

The main objective of this project is to identify key factors affecting employee performance, salary growth, promotions, and employee retention.

This analysis helps HR departments make data-driven decisions, improve workforce productivity, understand employee satisfaction, and develop effective employee retention strategies.

## 🎯 Project Objectives

- Analyze employee distribution across departments.
- Understand salary distribution and salary differences.
- Identify top-performing and highest-paid employees.
- Analyze employee experience and performance ratings.
- Evaluate department-wise employee productivity.
- Understand work mode distribution (Remote, Hybrid, Office).
- Analyze employee attrition and retention.
- Explore the relationship between experience and salary.
- Identify gender-wise and education-wise employee distribution.
- Build an interactive HR Analytics Dashboard.

## 🗄️ SQL Analysis

The following SQL operations are performed:

- Total number of employees in each department.
- Department-wise average salary.
- Top 10 highest-paid employees.
- Average years of experience by department.
- Employees with the highest performance rating.
- Employee count by work mode.
- Departments with the highest attrition.
- Employee salary ranking within each department using Window Functions.
- Employees earning above the company average salary.
- Gender-wise employee distribution.

**SQL Concepts Used:**
- SELECT, WHERE, GROUP BY
- ORDER BY, HAVING
- Aggregate Functions (COUNT, AVG, MAX)
- Subqueries
- Joins
- CASE Statements
- Window Functions (RANK, DENSE_RANK)
